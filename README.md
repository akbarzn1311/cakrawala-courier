Cakrawala Courier is a 3D courier flight game over an Indonesian archipelago, built with three.js. Take off from the runway, fly through six glowing rings in order, then land to deliver the parcel — with fuel, damage and the clock all working against you. Chase camera, lit instruments (speed, altitude, heading, throttle, fuel, attitude), procedural terrain, sea, town and mountains, and procedural WebAudio engine and wind.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network: everything the game loads is a file under `game/`.
